## Plans 009–015: mode rationale (audit-driven, 2026-09-09)

These plans come from a code-health audit of `main @ 2178509`. Execution
mode was chosen per plan by the nature of the change, not by default:

- **Direct edit** (009, 011, 012, 013, 015): behavior-preserving moves and
  typing refactors already pinned by the existing suite + pyright + ruff.
  Strict TDD would add ceremony without signal; the gates ARE the existing
  verification commands.
- **Strict TDD** (010): the only plan that changes an error contract —
  new typed exceptions and log-based observability while preserving the
  public `bool` API. RED→GREEN→REFACTOR per step, failing output quoted.
- **Test-only characterization** (014): no production change allowed; a
  failing new test = discovered bug = STOP and report.
- **No SDD cycles**: none of the findings introduce user-facing surface,
  new profiles, or cross-cutting specs — a full explore→spec→design cycle
  would be process without product. SDD remains the right tool for the
  next FEATURE (like plans 005–007), not for debt remediation.

## Execution-mode conventions (apply to every plan)

- **Default**: dispatch `Task(subagent_type="medium", ...)` with `CAP:5` and an
  `[acceptance]` block. Inline the **full content** of every oracle file a step
  references — path-only references produce poor results from implementation
  subagents.
- **Strict TDD**: RED (failing test, quoted in the step report) → GREEN (minimal
  implementation) → REFACTOR. No implementation before its failing test exists.
- **SDD** (plan 005 only): explore → propose → spec (scenarios) → design → tasks
  → apply (via @medium per task) → verify. Automated SDD artifacts are saved
  with `capture_prompt: false`.
- **Orchestrator rule**: re-verify every gate in your own shell before marking a
  plan DONE. Prior sessions recorded false claims by subagents ("winax not
  available", "0 errors in 70 runs") that direct runs disproved.
- **COM hygiene**: kill stray Access before and after COM test runs
  (`taskkill /F /IM MSACCESS.EXE` if needed); never mutate canonical fixtures;
  mutating tests operate on temp copies and verify the source hash afterwards.
- **Commits**: conventional commits, English, no AI attribution. Branch per plan:
  `plan/NNN-<slug>`. Do not push unless instructed.
