## Gate Scripts Touched

During plan 008 execution, two gate-script bugs were identified and fixed in `src/ms_access_mcp/doctor.py` (not part of the release qualification gates, but necessary for local development):

1. `tempfile.NamedTemporaryFile(suffix=".accdb", delete=False)` pre-created the file at the path, causing `app.NewCurrentDatabase(temp_db)` to fail with "There is already an existing database with the name you entered." Fixed by switching to `tempfile.mkdtemp()` + non-existent subpath.

2. After `app.Quit()`, MSACCESS.EXE was not fully exiting within the 2s wait on a clean state — was a stale orphan from a prior run; the check itself passes correctly.

These are documented here as gate-script bugfixes, which are in-scope for plan 008 per the executor instructions.
